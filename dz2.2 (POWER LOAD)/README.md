# ДЗ 2.2 — Пасивні/Активні: як підключити потужне навантаження (POWER LOAD)

Три прошивки на **ESP32-S3-DevKitC-1** про те, що робиться між мікроконтролером і навантаженням: реле з його механікою, транзисторний ключ із ШІМ і одна нахабна ідея зробити ШІМ із UART.

## Прошивки

- [`relay_timing`](relay_timing/) — завдання 1: реле на GPIO через ключ BC547B, сухий контакт на `INPUT_PULLUP` із перериванням по `CHANGE`. Серія з 15 циклів, окремо час до першого фронту і окремо тривалість брязкоту контакту.
- [`motor_pwm`](motor_pwm/) — завдання 2: TT-моторчик через ключ 2N2222A, швидкість із потенціометра, ШІМ формується руками на `micros()`. Плюс статистика запізнення фронтів — скільки коштує софтовий ШІМ.
- [`uart_pwm`](uart_pwm/) — експеримент: безперервний потік одного байта в Serial1 перетворює лінію TX на генератор із заданою шпаруватістю. `0x00`, `0x0F`, `0x55`, `0xFF` під логічним аналізатором.

## Де що в коді

| Пункт завдання | Де |
|---|---|
| GPIO керує обмоткою реле через ключ | `COIL_PIN` + BC547B у `relay_timing` |
| Інший GPIO читає сухий контакт, `INPUT_PULLUP` | `CONTACT_PIN`, `COM` реле на GND |
| `micros()` і `attachInterrupt` для виміру | `onContactEdge()` з `IRAM_ATTR`, час береться першим рядком ISR |
| Врахувати брязкіт контактів | ISR пише перший фронт, останній і лічильник; перемикання зараховане після 5 мс тиші |
| Не менше 10 вимірювань, середнє вмик/вимк | `CYCLES = 15`, підсумок із avg/min/max, закріплено `static_assert` |
| Потенціометр через ADC | клас `Potentiometer` у `motor_pwm`, ковзне середнє по 8 вимірах |
| ADC → тривалість високого й низького рівня | `SoftPwm::setDuty()` |
| ШІМ на `micros()` | `SoftPwm::tick()`, неблокуючий, без `delayMicroseconds()` |
| Плавна зміна швидкості | мертва зона біля нуля + діапазон від `MIN_DUTY` до 100 % |
| UART як джерело ШІМ | `uart_pwm` цілком |

## Ключі: який транзистор під яке навантаження

| | Максимум колектора | Куди поставив |
|---|---|---|
| BC547B | 100 мА | вхід модуля реле (одиниці мА) |
| 2N2222A | 800 мА | TT-моторчик (~150 мА на вільному валу) |

Той самий BC547B, яким у [ДЗ 1.7](../dz1.7%20%28TWILIGHT%20SWITCH%29/) я керував реле, для двигуна не годиться — його стеля нижча за робочий струм мотора. Розрахунок резистора в базі і решта силової обв'язки (flyback-діод, конденсатор по живленню, спільна земля) розібрані в README варіанта [motor_pwm](motor_pwm/).

## Схеми в Wokwi

Wokwi не має жодної силової деталі: ні двигуна постійного струму, ні діода, ні конденсатора, ні транзистора. Тому в [motor_pwm](motor_pwm/) кожна з них — окремий кастомний чип із правильною кількістю виводів, а не один прямокутник замість усієї обв'язки. Двигун при цьому не просто намальований: він сам міряє шпаруватість на своєму мінусі й крутить ротор відповідно. Вихідники чипів і `Makefile` лежать у [`motor_pwm/chips/`](motor_pwm/chips/).
