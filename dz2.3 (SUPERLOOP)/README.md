# ДЗ 2.3 — Superloop та незалежні задачі (SUPERLOOP)

Три світлодіоди блимають з різними періодами в одному `loop()`, не заважаючи один одному: 200, 500 і 1000 мс. Плата — ESP32-S3-DevKitC-1.

## Прошивки

- [`three_leds`](three_leds/) — задача одного світлодіода винесена в клас `LED` із власним таймером на `millis()`; `loop()` просто викликає `update()` у трьох об'єктів.

## Де що в коді

| Вимога | Де |
|---|---|
| LED1 блимає кожні 200 мс | `redLED` на GPIO 4 |
| LED2 блимає кожні 500 мс | `greenLED` на GPIO 5 |
| LED3 блимає кожні 1000 мс | `yellowLED` на GPIO 6 |
| Без `delay()` | в коді немає жодного виклику |
| Без `while()` для очікування часу | єдина перевірка часу — `if` у `LED::update()` |
| Таймінг на `millis()` | `currentTime - lastToggleTime_ >= interval_`, поле в кожного об'єкта своє |

Розбір і цифри з таблиці символів — у README варіанта [three_leds](three_leds/).
