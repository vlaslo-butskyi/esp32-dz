# ДЗ 2.9 — guard (SETUP LOOP)

Цей приклад показує, від чого захищає сторожа заголовка і від чого не захищає. Опційний пункт умови 2.9 вимагає механізм проти циклічного `#include` в `app.h`.

У прошивці [`blink`](../blink/) є тільки один заголовок, і циклу в ньому немає. Тому цикл зібрано тут окремо, на двох заголовках.

| Файл | Що додає через `#include` | Навіщо |
|---|---|---|
| `app.h` | `board.h` | потрібен тип `BoardPins` |
| `board.h` | `app.h` | потрібен тип `AppConfig` |

Кожен із двох модулів посилається на інший. Для прикладу STM32 не потрібен: його збирає компілятор комп'ютера.

## Запуск

Запустіть скрипт з цієї папки:

```sh
./run.sh
```

## Результати

Скрипт збирає той самий цикл із чотирма ключами:

| Ключ | Що змінює | Що повідомляє компілятор |
|---|---|---|
| `-DNO_GUARD` | вимикає сторожі в обох заголовках | `app.h:12: error: #include nested too deeply` |
| — | нічого, сторожі на місці | `board.h:18: error: unknown type name 'AppConfig'` |
| `-DBOARD_FIRST` | першим додає `board.h` | `app.h:15: error: unknown type name 'BoardPins'` |
| `-DFIXED` | `board.h` більше не додає `app.h` | збирається без помилок |

Сторожа не розриває циклічну залежність. Вона тільки зупиняє нескінченний `#include` у препроцесорі. Це показують другий і третій рядки таблиці.

Цикл залишається. Заголовок, який `#include` додав другим, стає порожнім текстом. Тоді файл, який його додав, не бачить потрібного типу. Інший порядок `#include` теж не допомагає: помилка переходить в інший заголовок, як показує третій рядок.

## Як розірвати цикл

Цикл розриває оголошення наперед (ключ `-DFIXED`):

```c
typedef struct AppConfig AppConfig;   // замість #include "app.h"
```

Для параметра-вказівника цього досить. Компілятору не потрібен розмір структури, тільки факт, що тип існує. Так само в C оголошують дві структури, які посилаються одна на одну.

## Навіщо сторожа

Сторожа потрібна навіть без циклу. Два різні файли можуть додати той самий заголовок. Без сторожі заголовок удруге оголосить свої `typedef` і `struct`, і компілятор покаже помилку.
