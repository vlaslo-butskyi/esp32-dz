# ДЗ 6.1 — ДЗ 2.3 на задачах FreeRTOS (RTOS TASKS)

Цей документ описує ДЗ 6.1. Умова: повторити [ДЗ 2.3](../dz2.3%20%28SUPERLOOP%29/three_leds/) через `xTaskCreate` або `xTaskCreatePinnedToCore`.

У ДЗ 2.3 три світлодіоди блимають незалежно з інтервалами 200, 500 і 1000 мс. Прошивка `three_tasks` використовує ту саму плату й схему, а фреймворк — ESP-IDF.

| Прошивка | Плата | Опис |
|---|---|---|
| [`three_tasks`](three_tasks/) | ESP32-S3-DevKitC-1 | відповідь на умову: три задачі, `vTaskDelayUntil` замість `millis()` |
| [`three_tasks_stm32`](three_tasks_stm32/) | WeAct Black Pill, STM32F411 | та сама прошивка на STM32 HAL і FreeRTOS 10.3.1, поза умовою |

## Що змінилось порівняно із суперциклом

| | ДЗ 2.3 (суперцикл) | ДЗ 6.1 (FreeRTOS) |
|---|---|---|
| одиниця роботи | об'єкт `LED` з методом `update()` | задача `blink_task`, три екземпляри |
| хто стежить за часом | кожен об'єкт: `millis() - last >= interval` | планувальник: `vTaskDelayUntil` |
| що робить процесор між перемиканнями | виконує `loop()` без корисної роботи | задачі заблоковані, ядро вільне |
| що буде, якщо одна задача зависне | зупиняться всі три світлодіоди | інші задачі працюють далі |
