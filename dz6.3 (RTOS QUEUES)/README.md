# ДЗ 6.3 — черги FreeRTOS (RTOS QUEUES)

Цей документ описує ДЗ 6.3. Умова: реалізувати безпечну передачу даних від кількох датчиків до одного Consumer через `xQueue`.

| Прошивка | Плата | Опис |
|---|---|---|
| [`sensor_queue`](sensor_queue/) | ESP32-S3-DevKitC-1 | відповідь на умову, ESP-IDF |

## Як прошивка виконує умову

| Вимога умови | Рішення в прошивці |
|---|---|
| кілька датчиків | вбудований датчик температури (`temp`), потенціометр на АЦП (`pot`), кнопка BOOT через ISR (`button`) |
| один Consumer | задача `consumer` на ядрі 1, єдиний читач черги |
| передача через `xQueue` | `xQueueCreate`, `xQueueSend` у задачах, `xQueueSendFromISR` в ISR, `xQueueReceive` у `consumer` |
| безпечно | дані між задачами передає тільки черга, вона копіює повідомлення цілим |

Задача `consumer` також показує в лозі збої передачі:
- загублені повідомлення за розривом у номері `seq`;
- датчик, який мовчить 3 свої періоди;
- повну чергу й найбільшу глибину черги.

Прошивку перевірено на платі й у симуляторі Wokwi. Логи й експеримент з повільним `consumer` описано в README прошивки.
